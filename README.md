# Yunjik · kwakyun

일상과 지역의 문제를 소프트웨어로 풀어보며 배우는 학생입니다.
서비스를 만드는 경험과 함께 알고리즘·자료구조, ROS 통신의 기본기를 쌓고 있습니다.

다양한 프로젝트를 직접 구현하며 실력을 쌓아가고 있습니다.
아이디어를 MVP로 구현한 경험을 바탕으로, 설계 이유와 검증 결과를 설명할 수 있는 개발자로 성장하고 싶습니다.
